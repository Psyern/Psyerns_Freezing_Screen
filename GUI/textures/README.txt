DME_Cold Overlay Textures
=========================

This folder contains overlay textures for frost, toxic, and blood effects.

FROST TEXTURES (Cold/Freezing Effect)
-------------------------------------
- Freeze1.paa (lightest frost - level 1)
- Freeze2.paa (level 2)
- Freeze3.paa (level 3)
- Freeze4.paa (level 4)
- Freeze5.paa (level 5)
- Freeze6.paa (level 6)
- Freeze7.paa (heaviest frost - level 7)

- toxic4.paa (level 4)

Image Requirements:
-------------------
- Format: .paa (DayZ texture format)
- Resolution: 1920x1080 recommended (will be scaled to fit screen)
- Alpha channel: Required for transparency
- Frost images: White/blue ice overlay, progressive coverage
- Toxic images: Green/yellow poison overlay, progressive coverage
- Blood images: Red vignette overlay, progressive coverage

Converting Images to PAA:
-------------------------
1. Create your PNG/TGA images with alpha channel
2. Use DayZ Tools (ImageToPAA) or Pal2PacE to convert
3. Place the .paa files in this folder with correct names
